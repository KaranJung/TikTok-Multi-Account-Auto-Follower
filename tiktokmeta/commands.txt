--------------------------------------------------------------------------------
COMMAND OPTIONS BREAKDOWN:
--------------------------------------------------------------------------------
-c <path>         : Path to folder containing .txt or .json cookie files
--deep            : Launches browser workers to audit live followers/following and deactivated status
-w <num>          : Number of parallel browser instances for deep audit (default: 2, recommended: 2-5)
--sort            : Automatically organizes cookie files into country folders (e.g. by_country/br/, by_country/es/)
--export <name>   : Custom output base name for JSON and CSV reports (default: cookie_audit_report)
